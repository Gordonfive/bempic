# Decision 0002: v0.1 Semantics Before Wire Freeze

**Status:** Accepted

**Date:** 2026-08-31

## Context

The generation-0 Python proof validates useful behavior but its encoding was
designed to be disposable. Independent implementations nevertheless need exact
state, identity, bound, persistence, failure, and compatibility rules.

## Decision

Version 0.1.0 standardizes a transport-independent semantic core and an exact
contract that any codec profile must satisfy. It does not select a permanent
codec or assign stable operation bytes.

Codec profiles are pluggable and must publish declarative bounds and precision,
maximum encoded sizes, exact per-value sizing, schema fingerprints, strict
decoding behavior, and byte vectors. DCCL is prior art for these design
qualities only; BEMPIC does not adopt DCCL, its wire format, encryption,
implementation language, or Protobuf dependency.

## Consequences

- Prototype identifiers and records are not compatibility authority.
- Semantic conformance and codec-profile conformance are separate claims.
- A later codec decision may change bytes during major-zero development.
- The v0.1.0 tag still requires executable proof of at least one reviewed
  experimental codec and independent vector agreement.
